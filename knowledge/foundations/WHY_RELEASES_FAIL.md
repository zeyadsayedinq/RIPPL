# Why Releases Fail

Diagnostic file. Match the symptom, jump to the fix.

| Symptom | Real cause | Fix |
|---|---|---|
| Good song, no streams | No pitch submitted in time | `checklists/DSP_PITCH_CHECKLIST.md` — 4 weeks minimum |
| Spike then flatline | Feed-only strategy, no catalog floor | `systems/CATALOG_COMPOUNDING_MODEL.md` |
| Views but no saves | Content and song target different people | `marketing/CONTENT_PILLARS.md` |
| High spend, low ROAS | Creative fatigue, not audience failure | `marketing/UGC_CONTENT_ENGINE.md` — rotate 12 hooks |
| Release slipped 3× | No blocking calendar, no owner per task | `/tasks` + `systems/RELEASE_OPERATING_SYSTEM.md` |
| Money "disappeared" | Splits agreed verbally, invoiced late | `templates/ROYALTY_SPLIT_SHEET.csv`, `/invoices` |
| Contract surprise | No expiry engine, no review checklist | `/vault` alerts + `checklists/CONTRACT_REVIEW_CHECKLIST.md` |
| Team confusion | Roles not assigned per asset | `/admin` assignments |

## The five failure patterns

1. **Late pitch.** Editorial consideration effectively closes ~4 weeks out. This
   single mistake kills more releases than any creative issue.
2. **One asset.** A campaign with one video has no way to learn. Minimum 8–12
   creative variants before judging the audience.
3. **No floor.** Everything is bet on release week. Catalog and search surface
   are what pay in month 4.
4. **Unowned tasks.** A checklist with no name against each row is a wish list.
5. **Unmeasured spend.** If a spend can't be traced to a campaign line in
   `/budget`, it will be repeated next cycle regardless of outcome.
