# TikTok / Short-Form Growth System

## Objective hierarchy

1. **3-second retention** — did the hook work
2. **Completion rate** — did the edit hold
3. **Saves + shares** — did it mean something
4. **Follows** — did they want more
5. Views — an output, never a target

## Posting model

| Variable | Setting | Rationale |
|---|---|---|
| Cadence | 1×/day per platform, 5 days/week | Enough samples to learn in 2 weeks |
| Variant strategy | Same body, different hook | Isolates the variable |
| Sound | Your own track, always | Sound page = free catalog surface |
| Caption | One line, restates the hook | Duplicated hook improves retention |
| Comment pin | The objection or the payoff | Extends watch time |

## The sound page

Every post using your own audio builds one shared, permanent asset: the sound
page. Treat it as catalog. Name the sound exactly as the track is titled on DSPs
so search intent transfers.

## 14-day test protocol

- Days 1–10: post 10 variants, one hook change each
- Day 11: rank by 3s retention
- Day 12: rebuild top 2 hooks with 3 new bodies each
- Days 13–14: post those 6
- Then: boost the single best per `systems/LOW_BUDGET_PROMO_MODEL.md`

## Common failures

- Changing three variables per post → learn nothing
- Judging at 24 hours → short-form has a long tail; judge at 72h minimum
- Using trending audio for a music campaign → promotes someone else's catalog
- Deleting "failures" → they're your control group

## Checklist

- [ ] Own audio on 100% of music posts
- [ ] One variable changed per variant
- [ ] Ranked at 72h on 3s retention
- [ ] Sound page named identically to DSP title
