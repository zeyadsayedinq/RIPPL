# Live Show Advance Checklist

Run for every confirmed date. Tracked in `/live`.

## Before confirming
- [ ] Break-even ticket count computed and written down
- [ ] Guarantee vs door split understood in writing
- [ ] Capacity and realistic sell-through estimate
- [ ] Travel + accommodation + crew costed
- [ ] Date doesn't collide with the release calendar in `/calendar`

## Advance (T−3 weeks)
- [ ] Promoter contact confirmed; day-of contact and phone number
- [ ] Load-in, soundcheck, doors, set time, curfew — all in writing
- [ ] Stage plot and input list sent
- [ ] Backline: what's supplied vs what you bring
- [ ] Playback/DJ format confirmed (USB, laptop, timecode) + backup
- [ ] Hospitality and green room
- [ ] Guest list count
- [ ] Merch: allowed? commission rate? who sells?
- [ ] Photo/video permissions

## Ticketing (T−3 weeks → door)
- [ ] On-sale date set; announcement assets ready
- [ ] Ticket tiers and prices set in `/live`
- [ ] Presale code distributed to the email list first
- [ ] Sell-through tracked weekly against break-even
- [ ] Escalation plan if sell-through < 40% at T−1 week

## Day of
- [ ] Arrive for load-in, not for soundcheck
- [ ] Line check every input
- [ ] Set times confirmed with the sound engineer
- [ ] Merch counted in
- [ ] Content capture assigned to a named person
- [ ] Settlement expectations restated before the show, not after

## After
- [ ] Merch counted out; reconcile
- [ ] Settlement signed and photographed
- [ ] Actual vs break-even logged in `/live`
- [ ] Email list captured at the door added to CRM
- [ ] Content edited and posted within 48 hours
