# Release Day Checklist

Run top to bottom. Tick in `/tasks`. Nothing is "obviously fine".

## T−24h
- [ ] Track is live on a test account in every target territory
- [ ] Artwork correct, no cropping on mobile
- [ ] Metadata: title, features, writers, ISRC, UPC all match the split sheet
- [ ] Explicit flag correct
- [ ] Pre-save link redirects to the live track (not to a 404)
- [ ] Smart link tested on iOS, Android, desktop
- [ ] Canvas / video loop uploaded
- [ ] Artist has the assets pack (12 hooks, endcards, links)
- [ ] Team knows who is on comms for the day

## Release hour
- [ ] Verify live on Spotify, Anghami, Apple, YouTube
- [ ] Content-ID badge checked in `/releases`
- [ ] Artist posts first (not the label account)
- [ ] Label/manager reshare within 30 minutes
- [ ] Story with link sticker + sound page link
- [ ] Sound page named identically to DSP title
- [ ] Creator briefs go live per `/creators` schedule

## First 6 hours
- [ ] Reply to every comment on the first 3 posts
- [ ] Pin the best comment
- [ ] Check for any DSP takedown / mismatch notice
- [ ] Note first-hour save rate

## End of day
- [ ] Log D0 numbers in `/dashboard`
- [ ] Log spend in `/budget`
- [ ] Note which hook performed best
- [ ] Schedule the D7 read

## Never on release day
- Never change the price/scope of anything
- Never launch a second unrelated campaign
- Never boost cold — wait for organic signal
