# Artist Onboarding Checklist

From "signed" to "operational". Should be complete within 14 days of signature.

## Legal & admin
- [ ] Executed agreement in `/vault` with expiry set
- [ ] Legal name, address, tax details collected
- [ ] PRO registration confirmed (or started)
- [ ] Publishing admin in place
- [ ] Split sheet template shared with the artist and explained
- [ ] Bank/payout details verified

## Digital
- [ ] Spotify for Artists / Apple / YouTube access granted to the team
- [ ] Social account access via a manager account, not shared passwords
- [ ] Artist profile assets updated everywhere: bio, photos, links
- [ ] Smart-link / landing page live
- [ ] Email capture live

## Catalog
- [ ] Existing catalog audited; ownership of every prior release confirmed
- [ ] Masters and stems collected into `/audio`
- [ ] Metadata errors on existing releases fixed
- [ ] Hit Score run on the top 5 tracks in `/hitlab`

## Operations
- [ ] Artist added in `/roster` with stage = Signed, managed = true
- [ ] Assigned to a team member in `/admin`
- [ ] 90-day development plan written (`foundations/AR_AND_ARTIST_DEVELOPMENT.md`)
- [ ] First release window blocked in `/calendar`
- [ ] Content cadence agreed and written down
- [ ] Communication norms set: which channel, expected response time

## Financial
- [ ] Budget band agreed and entered in `/budget`
- [ ] Recoupment terms explained to the artist in plain language
- [ ] Reporting cadence agreed
