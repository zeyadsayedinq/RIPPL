# Weekly Execution Template

## Monday — Plan (30 min)
- [ ] Read last week's scorecard
- [ ] Pick **one** primary outcome for the week (not three)
- [ ] Render 4 new hook variants
- [ ] Confirm every release gate due this week has an owner
- [ ] Check `/vault` expiry alerts and `/invoices` overdue badge

## Tuesday–Thursday — Ship
- [ ] 1 post per platform per day
- [ ] Creative work in a protected block (no admin in this block)
- [ ] Client/creator replies inside 24h
- [ ] Log every spend in `/budget` the day it happens

## Friday — Read (45 min)
- [ ] Rank the week's posts by 3s retention
- [ ] Pick the single winner to amplify
- [ ] Update pipeline stages in `/roster` — evidence only
- [ ] Raise every invoice that is due
- [ ] Fill the KPI scorecard

## Weekend — Compound
- [ ] Amplification budget behind Friday's winner
- [ ] One catalog action (re-pitch, re-title, bundle, video version)
- [ ] Write down anything learned into `knowledge/`

## Rules
1. One primary outcome per week.
2. Admin never enters a creative block.
3. Nothing gets boosted that hasn't won organically.
4. If a gate slips, the date moves — the schedule doesn't compress.
